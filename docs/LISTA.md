# Pocket Pip — la lista grande

Marca: `[x]` hecho · `[ ]` pendiente. El dueño elige qué entra y en qué orden. Cada ítem lleva un número
para poder decir "hagamos el 4.12, 7.3 y 9.1".

## 1. Base y arranque
- [x] 1.1 Juego 100% nativo en Android (Godot 4.7, GPU del teléfono). Nada web.
- [x] 1.2 Intro "nioro" (la de Color Flow: esfera de cristal, luna, arco de luz, "sparks of life") **que no se puede saltar**.
- [x] 1.3 Guardado automático (cada 20 s, al cambiar algo y al salir).
- [x] 1.4 Las necesidades bajan aunque la app esté cerrada (con tope, Pip nunca llega a 0 de golpe).
- [x] 1.5 Firma fija: cada APK nueva se instala encima de la anterior sin perder la partida.
- [x] 1.6 "Los ojos": el juego se prueba solo y saca 30 capturas en cada cambio.
- [ ] 1.7 Botón "Actualizar" dentro del juego cuando hay una APK nueva en GitHub (como Star Nova).
- [ ] 1.8 Pantalla de ajustes: música, sonidos, vibración, idioma, créditos, privacidad.
- [ ] 1.9 Vibración suave al tocar a Pip y en los botones.
- [ ] 1.10 Idiomas: español, inglés, portugués (Brasil es un mercado enorme para este género).
- [ ] 1.11 Modo de bajo consumo para teléfonos viejos (sombras simples, 30 cuadros).
- [ ] 1.12 Nube: guardar la partida en Google Play Juegos (cambiar de teléfono sin perder nada).

## 2. Pip (el personaje)
- [x] 2.1 Pip de Star Nova en 3D con esqueleto: respira, parpadea, mueve orejas y cola con resorte.
- [x] 2.2 Cara expresiva: boca que se abre, dientes de ardilla, lengua, rubor que cambia.
- [x] 2.3 Sigue tu dedo con la cabeza y los ojos.
- [x] 2.4 Gestos solo (cuando lo dejas quieto): bostezar, rascarse la oreja, saludar, mirarse la cola, estirarse, festejar.
- [x] 2.5 Ánimo visible: triste = orejas y cabeza gachas, ojos caídos.
- [x] 2.6 Corre de una habitación a otra (galope de Star Nova).
- [ ] 2.7 **Repetir lo que dices con vocecita de ardilla** (lo más famoso de Talking Tom; usa el micrófono).
- [ ] 2.8 Pip crece: bebé → niño → adolescente → adulto (cambia proporciones y desbloquea cosas).
- [ ] 2.9 Mojado de verdad: pelaje oscuro y gotitas después de la ducha.
- [ ] 2.10 Pelaje "peludo" con sombreador (mechones con viento), ojos con reflejo del cuarto.
- [ ] 2.11 Estados: enfermo (necesita medicina), sucio (manchas), cansado (ojeras), aburrido.
- [ ] 2.12 Hipo, estornudos al oler flores, se asusta con truenos.
- [ ] 2.13 Elegir colores de pelaje (naranjo, gris, café, blanco, negro, galaxia...).
- [ ] 2.14 Nombre propio de la mascota y cumpleaños de Pip (regalo especial).
- [ ] 2.15 Modelo HD hecho en Blender (con IA gratuita para bocetos) para reemplazar las formas simples.

## 3. Caricias y toques
- [x] 3.1 Barriga → se ríe (risita sintetizada) y se tapa la panza.
- [x] 3.2 Nariz → "boop", se le cruzan los ojos y a veces estornuda.
- [x] 3.3 Acariciar la cabeza → cierra los ojos, ronronea, corazones.
- [x] 3.4 Cola → salta y se mira la cola. Orejas → las sacude. Pies → cosquillas.
- [x] 3.5 Si lo pinchas muchas veces seguidas se enoja (cachetes, brazos cruzados, pisotón).
- [x] 3.6 Premio pequeño de bellotas por cariño (con pausa, no es una fuente infinita).
- [ ] 3.7 Empujarlo: se tambalea y se cae de poto (física).
- [ ] 3.8 Hacerle cosquillas con un plumero (objeto de la tienda).
- [ ] 3.9 Cepillarle la cola (barra de "brillo de pelaje").
- [ ] 3.10 Chocar los cinco / puño.
