# Pocket Pip

Cuida a **Pip**, la ardilla de *Star Nova*: hazle cariño, dale de comer, báñala, hazla dormir, vístela con ropa,
decora su casa y juega minijuegos. Juego **nativo** para Android hecho con Godot. **Sin anuncios.**

**Descargar la APK de prueba:** https://github.com/aedojoseeduardo9-bit/Mi-Pocket-Pit/releases/latest/download/PocketPip.apk
